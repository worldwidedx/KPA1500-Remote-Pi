One-time client trust instructions

Windows · Chrome · Edge

  1. Download the public CA certificate.
  2. Open it and choose Install Certificate.
  3. Select Local Machine, then place it in Trusted Root Certification Authorities.
  4. Restart the browser.

macOS · Safari · Chrome · Edge

  1. Open the downloaded certificate in Keychain Access.
  2. Add it to the System keychain.
  3. Open the certificate, expand Trust, and choose Always Trust.
  4. Restart the browser.

iPhone · iPad

  1. Open the downloaded certificate and allow the profile.
  2. Install it under Settings → General → VPN & Device Management.
  3. Enable full trust under Settings → General → About → Certificate Trust Settings.

Android

  1. Download the certificate.
  2. Open Settings → Security → Encryption & credentials.
  3. Install it as a CA certificate.
  4. Restart the browser.

Install only the public .crt file. Never copy the private CA key from this Pi. Compare the displayed fingerprint before trusting it.
